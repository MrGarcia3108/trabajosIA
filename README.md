
# Trabajos de Inteligencia Artificial

## Descripción

Este repositorio contiene los ejercicios y actividades desarrollados durante las sesiones de trabajo relacionadas con Inteligencia Artificial e Ingeniería de Prompts. Cada sesión está organizada en su propia carpeta para facilitar la consulta y el seguimiento de las actividades.

## Organización del proyecto

```text
trabajosIA/
│
├── README.md
│
├── sesion1/
│   └── codigo.js
│
├── sesion2/
│   └── riwi-tres-cupos-borrador.txt
│
└── sesion3/
    │
    ├── PromptEngineering.md
    │
    └── proyecto/
        └── Archivos del proyecto clonado
```

## Ejercicios por sesión

### Sesión 1

- **Archivo:** `codigo.js`
- **Descripción:** Archivo de código JavaScript correspondiente a las actividades de la primera sesión.

### Sesión 2

- **Archivo:** `riwi-tres-cupos-borrador.txt`
- **Descripción:** Documento de texto con el borrador de la actividad correspondiente a la segunda sesión.

### Sesión 3

- **Archivo:** `PromptEngineering.md`
- **Descripción:** Documento relacionado con Ingeniería de Prompts y las actividades desarrolladas en esta sesión.

- **Carpeta:** `proyecto/`
- **Descripción:** Contiene el proyecto externo clonado mediante Git y almacenado dentro de la carpeta de la tercera sesión.

## Uso de Inteligencia Artificial

Durante el desarrollo de las actividades se utilizó ChatGPT como herramienta de apoyo para organizar información, estructurar documentos y resolver dudas.

### Prompt utilizado

> Quiero que organices toda la información que te proporciono en .md. organizada por secciones, conserva los detalles importantes y entrega el contenido en código listo para copiar y pegar en un archivo. Si el contenido es muy extenso, divídelo en partes.

### ¿Para qué se utilizó?

- Organizar información en documentos Markdown.
- Estructurar contenidos por secciones.
- Apoyar la documentación de las actividades.
- Resolver dudas sobre Git y Visual Studio Code.
- Orientar el proceso de clonación de proyectos dentro de carpetas específicas.

## Herramientas utilizadas

- Visual Studio Code.
- Git y GitHub.
- JavaScript.
- Markdown.
- ChatGPT como herramienta de apoyo.
